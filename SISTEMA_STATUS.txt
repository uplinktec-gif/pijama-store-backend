┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎯 PRÓXIMOS 3 PASSOS PARA ATIVAR WHATSAPP                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  PASSO 1: Terminal novo (não feche o que servidor tá rodando)
  ────────────────────────────────────────────────────────────
    $ ngrok http 3000

    Resultado:
    Forwarding  https://abcd1234.ngrok-free.app -> http://localhost:3000

    ➜ COPIE A URL (muda cada vez que reinicia!)


  PASSO 2: Acessar painel WhatsApp Business
  ──────────────────────────────────────────
    1. Vá para: https://business.facebook.com
    2. Selecione seu business
    3. WhatsApp > API Setup > Webhook > Edit
    4. Cole:
       • Callback URL: https://abcd1234.ngrok-free.app/api/webhook/whatsapp
       • Verify Token: seu_verify_token_arbitrario
       • Subscribe: ✓ messages
    5. Clique: Verify and Save

    ➜ Se vir ✅ Success: Tá funcionando!


  PASSO 3: Enviar mensagem de teste
  ──────────────────────────────────
    1. No celular, abra WhatsApp
    2. Envie: "2 zara g bordô pra joão"
    3. Aguarde resposta do sistema
    4. Verifique Google Sheets > PEDIDOS_E_VENDAS

    ➜ Se pedido apareceu: SISTEMA ESTÁ 🟢 ATIVO!
